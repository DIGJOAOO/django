1) Django es un fremework para desarrollar aplicaciones web utilizando Python.Facilita tareas como manejar urls, bases de datos, usuarios y páginas web.
2) MTV separa la aplicación en model, que maneja los datos, template, que se encarga de la presentación y view, que procesa las solicitudes y la lógica.Es similar al patrón MVC, donde model representa los datos, view la presentación y controller controla la lógica.La diferencia es que en django la view cumple gran parte de la función que normalmente realiza el controller en MVC.
3) Una app es un modulo que se encarga de una parte del proyecyo independientemente.Las apps permiten reutilizar codigos.
4) El flujo request-response comienza cuando el navegador envía una solicitud http al servidor django.Django analiza la url, encuentra la vista correspondiente y esta puede consultar datos, procesarlos y generar una respuesta.
5) ORM es una técnica que permite trabajar con una base de datos utilizando objetos y clases de python en lugar de escribir directamente todas las consultas sql.Django incluye su propio ORM, mediante el cual podemos crear, consultar, modificar y eliminar datos usando código Python.
6) Los templates son archivos que se utilizan para definir cómo se muestra la información al usuario.Permiten combinar html con datos dinámicos utilizando elementos propios de django para evitar repetir código.
8) En el tutorial se crea un proyecto django y una aplicación llamada polls, además de configurar sus urls y crear una primera vista.También se aprende a ejecutar el servidor de desarrollo y a conectar las urls del proyecto con las de la aplicación.
